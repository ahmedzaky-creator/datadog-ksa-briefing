Unified Service Tagging: The three magic tags.

Like a barcode on airline luggage, you tag telemetry once with env, service, and version. The platform automatically joins metrics, traces, logs, user sessions, security signals, and cloud costs—without custom query code.

env
Where the software runs. Separates prod from staging and isolates AWS Riyadh from on-prem datacenters.
env:prod-riyadh-az1
service
What business function the code performs. Defines microservice boundaries and operational ownership.
service:mada-payment-gw
version
Which exact build is running. Flags regression culprits the instant a new deployment lands.
version:v2.4.1-rc3
The Architectural Moat When a monitor fires, Watchdog ML doesn't say "something is slow"—it pinpoints: service:mada-payment-gw version v2.4.1 in env:prod-riyadh is throwing connection pool errors.
