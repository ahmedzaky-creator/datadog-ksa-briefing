NDMO Classification
Royal Decree No. 59888
 Establishes 4 data tiers. PII or financial data inherits Level 3 (Confidential), restricting unencrypted transfer. Raw logs with citizen data cannot egress cross-border without minimization. In-Kingdom Vector VRL strips PII, reducing telemetry to Level 1/2.
SDAIA PDPL
Royal Decree M/19 (Art. 19/29)
 Strictly governs cross-border transfer of Saudi citizen personal data; mandates data minimization. National IDs, Iqamas, mobile numbers, and IBANs must be eliminated prior to egress. Sensitive Data Scanner + client-side RUM DOM masking at the device.
SAMA CSF 3.3.14 & 3.4.3
Event Logging & Outsourcing
 Mandates 24x7 centralized event logging, automated correlation, and non-objection for cloud services. Banks must retain auditable transaction trails within Kingdom boundaries. Local AWS S3 In-Kingdom + Datadog Cloud SIEM for real-time alerting.
NCA ECC-2:2024 & CCC
Subdomain 2-12 (Logs)
 Mandates minimum 12-month log retention (18 months for Critical National Infrastructure). High storage volume requires low-cost compliance archiving without indexer sprawl. Flex Logs ($0.05/GB) on local S3 in Riyadh for 18-month retention.
CST Cloud Framework
CCRF Category C License
 Regulates cloud hosting facilities and government cloud workloads in Saudi Arabia. Enterprise cloud services must align with sovereign hosting standards. AWS Riyadh (me-central-2) local data centers with Zero&One delivery.
