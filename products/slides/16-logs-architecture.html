Logging Without Limits: Separating ingest from indexing.

Plain Language: Legacy tools like Splunk charge by the index volume, forcing companies to throw away 80% of their logs to avoid huge bills. Datadog decouples ingestion from indexing—so you ingest all logs for alerts, but only index what you search.

Decoupled Log Architecture

Ingest 100%, Index What Matters

All logs are ingested at $0.10/GB, parsed into JSON facets, evaluated for real-time alerting, and scanned for PII. You then dynamically route each log stream to its optimal cost tier.

1. Log Ingestion: $0.10 / GB ingested (Full real-time alerting & metrics)
2. 15-Day Active Index: $1.70 / 1M events (High-speed troubleshooting)
3. 30-Day Active Index: $2.50 / 1M events (Regulated transaction audit)
4. Sensitive Data Scanner: $0.10 / GB scanned (Auto-masks PII)
Zero Waste: Never drop logs again just to balance an IT budget.
