The Foundation Under Every Product

One agent. Kernel-level eBPF. Zero code changes.

Rather than installing 8 separate vendor daemons, the Datadog v7 agent hooks directly into the Linux kernel via eBPF. It observes every system call, network flow, and pod lifecycle event with under 1% CPU overhead.

System-Probe & eBPF: Hooks socket events, TCP handshakes, and process executions directly in kernel space without bytecode modification.
Autodiscovery & Dynamic Tracing: Detects new EKS pods instantly, injects Single-Step APM bytecode, and scrapes container metrics.
Single Secure TLS 443 Egress: Batches, compresses, and forwards all telemetry streams via one outbound tunnel, simplifying firewall rules.
