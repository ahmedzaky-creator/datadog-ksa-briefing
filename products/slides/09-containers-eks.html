Datadog Cluster Agent & HPA

Instead of running heavyweight agents in every container, the Datadog Agent runs as a DaemonSet, scraping kernel cgroups. The Cluster Agent aggregates cluster-level metrics and serves as an external metrics provider for Horizontal Pod Autoscaling (HPA).
