Enterprise Architecture Selection Guide

The four KSA blueprints: Matching architecture to regulatory tier.

Plain Language: Different organizations in the Kingdom have different regulatory classifications. Datadog provides 4 distinct deployment blueprints so you can match the architecture to your exact compliance mandate.

Recommended Enterprise

Blueprint 1: Sovereign Hybrid Edge

NDMO Level 3 · SAMA CSF · NCA ECC

Vector worker deployed in customer VPC. 100% raw logs stored on local AWS S3 in Riyadh for 18-month retention. VRL scrubs citizen PII before egressing sanitized metrics/traces to SaaS.

• Local S3 18-mo retention
• In-memory VRL PII scrub
• Full APM & Bits AI active
Zero Log Egress

Blueprint 2: BYOC Logs / CloudPrem

Tier-1 Banking & Government

All log indexing and storage remain 100% inside customer AWS Riyadh VPC powered by Quickwit. Federated query queries local S3 from SaaS UI without moving data.

• Zero raw logs leave KSA
• Customer KMS encryption
• Federated TLS search UI
Future State

Blueprint 3: Dedicated KSA Site

Sovereign Cloud Strategy

Dedicated multi-tenant Datadog control plane hosted entirely within AWS Riyadh data centers (me1.datadoghq.com). All telemetry stored and analyzed in-Kingdom.

• 100% in-country hosting
• Husky & Monocle in Riyadh
• Native CST Category C
Digital Native

Blueprint 4: Pure SaaS + Scanner

NDMO Level 1/2 · Startups & Retail

Direct agent telemetry egress protected by dual-layer redaction: client-side RUM DOM masking on consumer devices and Sensitive Data Scanner at intake.

• Client-side DOM masking
• Zero infrastructure to manage
• Fastest time to value
Architectural Decision Rule: For banks and national platforms launching in AWS Riyadh: Deploy Blueprint 1 today. It provides 100% compliance with local S3 retention, instant zero-PII scrubbing, and full access to Bits AI autonomous features.
