TRACE · EVERY STEPThe status tool visa_status() timed out three times, and the agent kept retrying. The answer took 11.8 s and three times the tokens it should.
QUALITY · EVALUATIONSWith no tool result, the model guessed a status. A hallucination evaluation flags the answer as unsupported before the citizen complains.
SAFETY · SENSITIVE DATAThe prompt contained a national ID number. Sensitive Data Scanner redacts it in prompts and completions before storage. AI Guard (limited availability) screens for prompt injection.
FIX · COST · GPUSThe trace points to the slow upstream API, not the model. Add a timeout and fallback, and the cost per answer, token spend and GPU utilisation sit on the same dashboard.
WHY IT MATTERS IN THE KINGDOMHUMAIN ONE launched as an enterprise agent platform, and HUMAIN Chat runs on ALLaM 34B. Agents are moving from pilot to citizen- and customer-facing services, where a wrong answer is a public one.
